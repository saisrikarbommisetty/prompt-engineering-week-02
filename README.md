# Week 02 – Baseline vs Enhanced Prompt Engineering

## 1. Aim

To understand and compare the effectiveness of baseline prompts and enhanced prompts by interacting with a Large Language Model using the Google Gemini API.

## 2. Objectives

- Understand the importance of prompt structure.
- Compare simple prompts with enhanced prompts.
- Implement role-based prompting.
- Provide context and specific instructions to an LLM.
- Use real-world analogies and examples to improve responses.
- Apply word limits to control generated output.
- Analyze the differences between baseline and enhanced responses.

## 3. Technologies Used

- **Programming Language:** Python

## 4. Experiment Description

This experiment demonstrates how prompt quality influences the responses generated by a Large Language Model.

The program establishes a connection with the Google Gemini API and sends two different prompts related to the concept of recursion.

### Baseline Prompt

"What is recursion?"

The baseline prompt provides a simple question without additional context or formatting instructions.

### Enhanced Prompt

"You are a computer science professor. Explain recursion to a beginner using a simple real-world analogy. Give a clear definition and one example. Keep the explanation under 50 words."

The enhanced prompt includes:
- **Role:** Assigns the model the role of a computer science professor.
- **Audience:** Specifies that the explanation is for a beginner.
- **Context:** Requests a simple real-world analogy.
- **Specific Instructions:** Requires a definition and one example.
- **Output Constraint:** Limits the explanation to fewer than 50 words.

Both prompts are submitted to the same Gemini model, and their generated responses are displayed for comparison.

## 10. Analysis

The baseline prompt provides only a general instruction, so the response may be less structured.

The enhanced prompt provides a specific role, context, real-world analogy, example requirement and word limit.

Therefore, the enhanced prompt is designed to produce a more focused, clear and beginner-friendly response.

## 12. Conclusion

This experiment demonstrates that effective prompt engineering involves more than asking simple questions. Providing clear roles, context, examples and output constraints helps guide Large Language Models toward the desired response format and level of detail.
